# PHASE 0 - Preparation
Before any designing or prototyping, establish two things: **production scope** and **market conditions**.

Deliverables for this phase are a **_production scope audit_** and a **_market conditions report_**.

---

This phase is done to establish the limitations, requirements, and expectations for your following game project.

_**For casual solo projects, this may be skipped. But for those looking to effectively produce and successfully publish a game, this may be worth considering.**_
